Example labs

A sample of what participants do. Tap a lab to open it.

Lab: deploy on every merge

Build a pipeline that tests a service, builds a container image and deploys it to a Kubernetes cluster, with a one-click rollback.

name: deploy
on: { push: { branches: [main] } }
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: make test
      - run: docker build -t app:${{ github.sha }} .
      - run: kubectl set image deploy/app app=app:${{ github.sha }}
Lab: alert on error budget burn

Define a 99.9% availability SLO and write an alert that fires when the budget is burning too fast, not on every blip.

- alert: HighErrorBudgetBurn
  expr: |
    sum(rate(http_requests_total{code=~"5.."}[1h]))
    / sum(rate(http_requests_total[1h])) > 14.4 * 0.001
  for: 5m
  labels: { severity: page }
Lab: threat model a payments API

Draw the data flow, mark trust boundaries and apply STRIDE. End with a ranked list of risks, each with an owner and a fix.

Lab: AI-assisted incident summary

Feed sanitised logs from a mock outage to an LLM, produce a timeline, then check every claim against the source logs.

Teams are paged for a failing release, find the cause with dashboards and logs, restore service and write the postmortem.
